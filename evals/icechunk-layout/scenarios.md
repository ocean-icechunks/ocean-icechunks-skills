# Scenarios: icechunk-layout

Run `test_scan.py` for the script (`ICECHUNK_LAYOUT_OFFLINE=1` skips the live scans).
These scenarios check the agent's behavior around it.

## 1. Design a new store

The user wants a virtual Icechunk store of a provider's regional ocean model, with
2-D and 3-D output in separate files, for a Source Coop product of their own.

## 2. Write a README for an existing product

The agent is asked to write the README for `ocean-icechunks/noaa-gomofs`.

## 3. Store at the root, no documentation

The user has put an Icechunk store at the root of a new Source Coop product, with a
build notebook beside it and no README, and asks for help publishing it.

## 4. Where is the store?

The user asks for the store URL and the docs of `ocean-icechunks/noaa-ohc`.
